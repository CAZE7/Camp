# Planer-Übersichtlichkeit — Recherche & Prototyp

Ergebnis der umfassenden Recherche „Wie wird der Elektroplaner übersichtlicher? (umschaltbare Ansichten / anderes Layout)“.

- **[`RECHERCHE.md`](./RECHERCHE.md)** — Ist-Analyse (beide Code-Stände), Normen- & UX-Grundlagen,
  Wettbewerber, **Maßnahmenkatalog (45+ Optionen in 8 Kategorien)**, Bewertungsmatrix,
  4-Phasen-Roadmap, Architektur-Vorschlag für ein View-System, offene Product-Entscheidungen.
- **[`prototyp/index.html`](./prototyp/index.html)** — interaktiver Prototyp mit 9 umschaltbaren Ansichten
  (Status quo, Einlinien-Übersicht, Stromschienen, Stromkreise, Kabelliste, Verlegeplan, Energiebilanz,
  Druckblatt, Split-Vergleich) über einer gemeinsamen Beispieldatenquelle. Ohne Build:
  Datei öffnen oder `python3 -m http.server --directory docs/planer-uebersicht/prototyp`.

Kein Produktcode: Der Prototyp ist Entscheidungs- und Kommunikationsmedium für die Auswahl der Ansichten.
