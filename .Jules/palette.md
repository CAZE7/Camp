## 2024-10-21 - Accessible Toggle Patterns for Component Categories
**Learning:** In highly customized, dense sidebars where components are grouped into expandable "accordion" style sections without using standard UI libraries, we must manually ensure robust ARIA linkages. A recurring pattern in custom list/accordion implementations is the omission of `aria-controls` on the toggle button linking it to the listbox. Furthermore, when the content is conditionally rendered (removed from DOM when closed), the `aria-controls` attribute must be conditionally set to `undefined` instead of pointing to a non-existent element to pass rigorous accessibility validation.
**Action:** When reviewing custom accordion or expandable section components, use React's `useId()` to generate a unique ID, assign it to the expandable `<div role="listbox">` (or similar container), and set `aria-controls={isOpen ? id : undefined}` on the toggle button alongside the `aria-expanded` attribute.
